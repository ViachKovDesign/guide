# IDODOM — два сайта

Две концепции сайта для IDODOM (Home priority): современная мебель, интерьер и дизайн.
Логотип воссоздан в векторе из исходника (слово, рамка с разрывом, подпись HOME PRIORITY) и стоит **по центру меню**.

Меню в обоих сайтах:

| слева | справа |
|---|---|
| Ракурсы · Разделы · О нас · Контакты | Мягкая мебель · Столы · Стулья и кресла · Фигуры |

## Как открыть

Двойной клик по `index.html` (лучше в Chrome) — сервер не нужен.
Откроется страница выбора, из неё — оба сайта.

```
idodom/
  index.html              страница выбора
  site-1-zal/             Сайт 1 «Зал» — тёмный, WebGL
  site-2-chertezh/        Сайт 2 «Чертёж» — светлый, React + framer-motion + Lenis
  assets/                 общие шрифты, библиотеки, видео, картинки, данные каталога
  tools/                  генератор картинок мебели
  previews/               превью для страницы выбора
```

## Сайт 1 «Зал»

Тёмный кинозал (эспрессо и крем, коньяк как редкий акцент).

- Вся страница живёт на одной WebGL-сцене (Three.js): зал с порталами и четырьмя постаментами. Камера ведётся функцией от прокрутки.
- **Ракурсы** — закреплённая секция: прокрутка обходит диван «Дуга» (фронт → три четверти → сверху → деталь).
- **Видео** мраморного стола раскрывается из рамки на весь экран, играет по кругу, клик — пауза.
- **Разделы** — камера летит вдоль зала; пункты правого меню подсвечиваются и ведут к своему постаменту.
- **Каталог** — лента карточек с фильтром; клик по карточке разворачивает её, внутри листаются соседние (стрелки, ←/→, колесо, свайп).
- Светлый экран «О нас», контакты с формой.

Стек: Three.js, GSAP + ScrollTrigger + Flip, Lenis. Всё лежит в `assets/vendor`, из интернета ничего не грузится.

## Сайт 2 «Чертёж»

Светлая бумага, тёмные кадры и разбивочная сетка с осями (клавиша `G` или кнопка «Сетка»).
Скролл и переходы сделаны по описанию bybang.co (React + framer-motion + Lenis, **без GSAP**):

- **Рельс** `.mosaic-rail`: высота `calc(var(--mosaic-loop-total-units) * var(--mosaic-row-unit))` — 2820 юнитов × ≈19,7 px ≈ 55 000 px. Внутри 216 кадров = 9 повторов набора из 24 (`data-mosaic-cycle` 0…8).
- Кадр задаётся четырьмя переменными: `--start`, `--cols`, `--top`, `--aspect-height-ratio`; `left`/`top` считаются через `--col-width` и `--mosaic-row-unit`. Раскладка собирается кодом (`src/layout.js`) без наложений, в том числе на стыках повторов.
- Вес прокрутки даёт только инерция Lenis, параллакса нет.
- Hover: `scale(1.04)` за 0,9 с; курсор — точка и название проекта (`data-cursor-label`).
- Вход кадров при первой загрузке: `y −150px` (на телефоне `92vh`), `scale .985`, `blur(14px)` → норма за 1,45 с, шаг 0,028 с (`--mosaic-entry-delay`).
- Переходы между страницами — `AnimatePresence mode="wait"` (`opacity 0, scale .94, blur(14px)` ↔ норма). Мозаика не размонтируется: на странице проекта она становится `position: fixed` и смещается через `--case-background-offset`.
- Страница проекта: гигантская бегущая строка (`ramp` + `marquee-linear`, от скролла не зависит), таблица меты слева, описание справа, асимметричная галерея, ссылка «Следующий проект», клавиши ←/→/Esc.
- Фильтр (Все / Мягкая мебель / Столы / Стулья и кресла / Фигуры): кадры не исчезают, а переезжают — `transition: top/left/width/height 1.12s cubic-bezier(.65,0,.35,1)` с задержкой `--i * .028s`.
- Производительность: `will-change` только там, где идёт анимация (вход, пересборка), `content-visibility: auto` у кадров, ленивые картинки.

Пересборка бандла (нужен Node 18+):

```bash
cd site-2-chertezh
npm install
npm run build        # → app.js
```

Исходники — `site-2-chertezh/src`. Готовый `app.js` уже лежит в репозитории.

## Что нужно заменить на настоящее

- **Картинки мебели** нарисованы кодом: модели в `assets/js/furniture.js`, генератор — `tools/render-products.js` (запускается через Playwright). Когда будут настоящие фото, просто положите их в `assets/img/p/` под теми же именами или поправьте пути в `assets/js/products.js`; для мозаики важно держать пропорцию (поле `r` = высота / ширина).
- **Каталог**: названия, размеры, материалы, описания, годы, телефон, почта — рабочие заготовки (`assets/js/products.js`, тексты контактов в обоих сайтах).
- **Форма** заявки ничего не отправляет: показывает подтверждение на странице. Подключите свой обработчик.
- **Видео**: `assets/video/table-interior.mp4` и `table-marble.mp4` — ваши ролики, пересжатые для сайта (без звука, H.264).
- Скриншот-референс с вертикальным видео (`video_…_2.mp4`, тёмный макет с проволочной мебелью) использован как ориентир по настроению, на сайте его нет.
