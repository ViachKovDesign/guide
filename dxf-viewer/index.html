Просмотр чертежей DXF

Перетащите сюда файл DXF

или нажмите «Открыть DXF». Файл никуда не отправляется — всё открывается прямо в вашем браузере.

Файл DWG не откроется. Сохраните чертёж из AutoCAD как DXF: «Файл → Сохранить как» → тип файла «AutoCAD DXF».
