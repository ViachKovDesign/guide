# Просмотр чертежей DXF в браузере

Открывает чертёж DXF без AutoCAD: перетащили файл на страницу — увидели чертёж.
Файл никуда не отправляется, всё работает в браузере. Сайт статический: сервер не нужен.

> **Статус: этап 1 из 3.** Готовы загрузка, отрисовка и навигация.
> Следующим этапом — слои, клик по объекту и рулетка (см. «Что дальше»).

## Что умеет сейчас

| Функция | Как работает |
|---|---|
| Загрузка | Перетащить файл на страницу или кнопка «Открыть DXF». Три готовых примера на стартовом экране |
| Отрисовка | Линии, полилинии (с дугами), дуги, окружности, эллипсы, сплайны, текст, многострочный текст, размеры, блоки (вложенные, массивы, с поворотом и отражением), штриховки (узоры и сплошные), выноски, точки |
| Не отрисовано | Под чертежом есть пометка «не отрисовано: N объектов»; по клику — список типов и сколько каждого. Ничего не пропадает молча |
| Навигация | Колесо — зум к курсору, перетаскивание — панорама, щипок двумя пальцами — зум на телефоне, кнопка «Показать всё» (клавиша `0`), клавиши `+` `−` и стрелки |
| Темы | Светлая и тёмная (фон как у модели в AutoCAD). Выбор запоминается |
| DWG | Не поддерживается. Интерфейс подсказывает: «Сохраните чертёж из AutoCAD как DXF» |

## Запуск

Нужен Node.js 20 или новее.

```bash
cd dxf-viewer
npm install
npm run dev        # открыть http://localhost:5173
npm test           # автотесты
npm run build      # готовый сайт в папке dist/
npm run preview    # посмотреть собранный сайт
```

Папку `dist/` можно положить на любой статический хостинг или просто открыть через
любой локальный веб-сервер (двойным кликом по `index.html` не откроется: браузеры
запрещают загружать модули и примеры с `file://`).

## Почему не dxf-viewer

Библиотека `dxf-viewer` быстрая (WebGL), но в ней нет выбора объектов мышью, а он нужен для клика по объекту
и рулетки с привязкой, и кодировка задаётся вручную, а `$DWGCODEPAGE` сама не читается.
Поэтому свой рендер на Canvas 2D. Готовый `dxf-parser` тоже не взял: он молча пропускает неизвестные
объекты (счётчик «не отрисовано» невозможен), а штриховок HATCH и веса линий слоя в нём нет.
Парсер написан свой, без внешних зависимостей.

## Кириллица

Старые DXF (до AutoCAD 2007) пишут текст не в UTF-8, а в кодовой странице из `$DWGCODEPAGE`.
Для русских чертежей это `ANSI_1251`. Как просмотрщик выбирает кодировку:

1. Версия R2007 и новее (`$ACADVER` ≥ AC1021) — всегда UTF-8.
2. Старая версия — берётся `$DWGCODEPAGE` (`ANSI_1251` → Windows-1251, `DOS866` → CP866 и т. д.).
3. Если кодовая страница не указана и файл не UTF-8 — считается Windows-1251.
4. Если заявлена одна кодировка, а содержимое — валидный UTF-8 с кириллицей (бывает у файлов из сторонних
   программ), верим содержимому.

Если всё равно кракозябры, справа внизу есть список «Кодировка» с ручным выбором.
Тексты вида `\U+0416` (так AutoCAD пишет символы, которых нет в кодовой странице) и спецкоды `%%c` (Ø),
`%%d` (°), `%%p` (±) раскрываются. Шрифт для отрисовки — Roboto Condensed с кириллицей, он лежит в сборке
(не подгружается из интернета), поэтому сайт работает офлайн.

> Шрифты AutoCAD (`.shx`, например GOST) в браузере недоступны, поэтому вместо них везде один шрифт.
> Высота букв сохраняется, ширина может немного отличаться.

## Что отрисовывается и что нет

Рисуется: `LINE`, `LWPOLYLINE`, `POLYLINE` (2D), `ARC`, `CIRCLE`, `ELLIPSE`, `SPLINE`, `TEXT`, `MTEXT`,
`ATTRIB`, `INSERT` (блоки), `DIMENSION` (через готовый блок размера), `HATCH`, `SOLID`, `TRACE`, `3DFACE`,
`LEADER`, `POINT`.

Учитывается: слои (цвет, выключен/заморожен), цвет по слою / по блоку / ACI / True Color, вес линий
(три-четыре градации толщины), типы линий (штриховые, осевые, пунктир), `$LTSCALE`, вектор выдавливания
(отражённые объекты), пространство модели. Объекты на слое «0» внутри блока наследуют слой вставки, как в AutoCAD.

Не рисуется и попадает в список «не отрисовано»: `MULTILEADER`, `XLINE`, `RAY`, `IMAGE`, `WIPEOUT`, `MLINE`,
3D-тела и поверхности, `OLE2FRAME`, `TABLE` и прочее. Пространство листа (вкладки Layout) не показывается:
число таких объектов выводится в том же списке.

## Тестовые файлы

В `public/samples/` лежат три файла, они же примеры на стартовой странице:

| Файл | Что проверяет |
|---|---|
| `detail-1251.dxf` | R2000, Windows-1251. Деталь со скруглениями, отверстиями, пазом; пять размеров (линейные, диаметр, радиус); блок «болт» с поворотом, масштабом и массивом; штриховка и заливка; русские надписи, `%%c`, `%%d`, MTEXT с переносами |
| `roof-node-1251.dxf` | R2000, Windows-1251. Кровельный узел: штриховки с узорами (в том числе с дугой в контуре), сплайн, эллипс, вложенные блоки, отражённая вставка, цвет по блоку, угловой размер, выноска; а также XLINE, RAY и MULTILEADER — для проверки списка «не отрисовано» |
| `facade-utf8-r2018.dxf` | R2018, UTF-8. True Color, вес линий, выключенный слой, дуга с отрицательным вектором выдавливания, объект на листе, одинокий объект в 90 км от чертежа (проверка «Показать всё») |

Файлы создаёт библиотека `ezdxf` (Python), а не наш парсер, поэтому тесты не повторяют наши же ошибки.
Пересоздать: `pip install ezdxf && python3 tools/make_samples.py`.

## Как разбирать ваши настоящие файлы

Присылайте реальные DXF. По каждому будет составлен список «что нарисовалось неправильно»
(скриншот просмотрщика рядом со скриншотом из AutoCAD), и каждая ошибка исправляется отдельным
коммитом с тестом. Подсказка для самопроверки: если внизу «не отрисовано: N» — откройте список,
там названы типы объектов.

## Производительность

Замеры на синтетическом чертеже: 300 000 линий, 50 000 окружностей, 20 000 подписей (23 МБ).

| Что | Время |
|---|---|
| Чтение, разбор и построение сцены | около 2,5 с |
| Кадр при «Показать всё» (все 370 тысяч объектов) | около 160 мс |
| Кадр при приближении ×8 | около 40 мс |

Типичный узел (тысячи–десятки тысяч объектов) рисуется заметно быстрее. Если будут файлы тяжелее, в планах
вынести разбор в Web Worker и рисовать при перемещении упрощённо.

## Устройство

```
index.html            страница
src/main.ts           сборка интерфейса: загрузка файла, строка состояния, темы
src/style.css         оформление, светлая и тёмная тема
src/dxf/decode.ts     байты → текст, выбор кодировки
src/dxf/parse.ts      текст → секции, таблицы слоёв/линий/стилей, блоки, объекты
src/dxf/scene.ts      объекты → примитивы в мировых координатах (блоки раскрыты)
src/dxf/geom.ts       матрицы, дуги по bulge, сплайны (NURBS)
src/dxf/text.ts       %%-коды, \U+, форматирование MTEXT
src/dxf/aci.ts        палитра цветов AutoCAD
src/dxf/units.ts      $INSUNITS → миллиметры
src/render/renderer.ts  Canvas 2D: линии пачками по стилю, штриховки, текст
src/render/fit.ts     границы для «Показать всё» без далёких одиночных объектов
src/ui/controls.ts    колесо, перетаскивание, щипок, клавиатура
tools/make_samples.py генератор тестовых файлов
tests/                автотесты (vitest)
```

Разбор не зависит от браузера (нет обращений к DOM), поэтому его можно запускать в тестах и,
при необходимости, перенести в Web Worker.
