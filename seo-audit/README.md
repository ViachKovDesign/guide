# Аудит сайта — запуск в одну команду

Скрипт `audit.py` проверяет сайт по 60+ пунктам: техническое SEO, мета-теги,
скорость, микроразметка, доверие и конверсия, требования 152-ФЗ.
Пишет понятный отчёт на русском в файл `audit-report.md`.

Нужен только Python 3 — ничего доустанавливать не надо.

## Как запустить

**1. Проверить живой сайт** (самый полный вариант):

```
python audit.py https://kovalenko-psychologist.ru/
```

Проверит всё: редиректы, HTTPS, robots.txt, карту сайта, 404, скорость,
сжатие, мета-теги, Open Graph, микроразметку, картинки, тексты, аналитику.

**2. Проверить сохранённую страницу** (если сайт не открывается из сети):

Откройте сайт в браузере → `Ctrl+S` → сохраните как `stranica.html` → затем:

```
python audit.py stranica.html
```

Разберёт всё, что видно в коде страницы. Пропустит только сетевые проверки
(редиректы, robots.txt, скорость) — для них нужен доступ к сайту.

**3. Своё имя файла отчёта:**

```
python audit.py https://site.ru/ --out otchet.md
```

## Как читать отчёт

| Метка | Значение |
|---|---|
| `[!!]` | Критично — чинить первым, это прямо стоит клиентов |
| `[! ]` | Важно, но не горит |
| `[ok]` | В порядке |
| `[i ]` | К сведению |

В конце отчёта — список «Что чинить в первую очередь».

## Если Python не установлен

Windows: скачайте с python.org, при установке обязательно поставьте галочку
**«Add Python to PATH»**. Потом откройте папку со скриптом, наберите в адресной
строке проводника `cmd` и введите команду запуска.
