# Набор правок для сайта психолога

Готовые куски кода и текста. Их нужно вставить на сайт — порядок в файле
совпадает с порядком приоритета: сверху то, что быстрее всего вернёт клиентов.

---

## 1. Микроразметка Schema.org

Ставится в `<head>`. Без неё Яндекс и Google не понимают, что на сайте —
конкретный специалист, и не показывают расширенный сниппет.
Подставьте свои данные вместо значений в кавычках.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "name": "Психолог Анна Коваленко",
  "url": "https://kovalenko-psychologist.ru/",
  "image": "https://kovalenko-psychologist.ru/foto.jpg",
  "description": "Системный семейный психолог. Консультации онлайн и очно.",
  "telephone": "+7XXXXXXXXXX",
  "priceRange": "3000-5000 RUB",
  "areaServed": { "@type": "Country", "name": "Россия" },
  "availableChannel": {
    "@type": "ServiceChannel",
    "serviceUrl": "https://t.me/Any_Kovalenko",
    "name": "Запись через Telegram"
  },
  "founder": {
    "@type": "Person",
    "name": "Анна Коваленко",
    "jobTitle": "Психолог, коуч",
    "knowsAbout": ["семейная терапия", "отношения", "тревога", "выгорание"],
    "alumniOf": { "@type": "EducationalOrganization", "name": "НАЗВАНИЕ ВУЗА" },
    "sameAs": ["https://t.me/Any_Kovalenko"]
  }
}
</script>
```

Блок вопрос-ответ даёт отдельный расширенный сниппет — добавьте, если на
сайте есть FAQ:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "Сколько длится консультация?",
    "acceptedAnswer": { "@type": "Answer", "text": "60 минут." }
  }, {
    "@type": "Question",
    "name": "Как проходит первая встреча?",
    "acceptedAnswer": { "@type": "Answer", "text": "Знакомимся, вы рассказываете запрос, намечаем план работы." }
  }]
}
</script>
```

Проверить готовую разметку: `webmaster.yandex.ru/tools/microtest/`

## 2. Превью ссылки в мессенджерах

Психолога рекомендуют перепостом. Без этих тегов ссылка в Telegram выглядит
голым адресом — по ней не кликают.

```html
<meta property="og:type" content="website">
<meta property="og:locale" content="ru_RU">
<meta property="og:url" content="https://kovalenko-psychologist.ru/">
<meta property="og:title" content="Психолог Анна Коваленко — консультации онлайн">
<meta property="og:description" content="Системный семейный психолог. Отношения, тревога, выгорание. Запись в Telegram.">
<meta property="og:image" content="https://kovalenko-psychologist.ru/preview.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">
```

Картинка строго 1200×630, с лицом и именем — по фото кликают лучше, чем по
абстракции. Проверить: вставьте ссылку в «Избранное» в Telegram.

## 4. Форма записи и 152-ФЗ

Любая форма, собирающая имя или телефон, обязана иметь галочку согласия и
ссылку на политику конфиденциальности. Без этого — штраф до 300 000 рублей.

```html
<form action="/send" method="post">
  <input type="text" name="name" placeholder="Как вас зовут" required>
  <input type="tel" name="tel" placeholder="Телефон или @ник в Telegram" required>
  <label>
    <input type="checkbox" name="agree" required>
    Я согласен на <a href="/politika/" target="_blank">обработку персональных данных</a>
  </label>
  <button type="submit">Записаться на консультацию</button>
</form>
```

Правила: не больше трёх полей. Каждое лишнее поле убивает часть заявок.
Кнопка — глагол и результат («Записаться на консультацию»), а не «Отправить».

Страница `/politika/` должна существовать и быть в подвале каждой страницы.

## 5. Яндекс.Метрика и цели

Без счётчика вы не знаете, сколько людей заходит и где они уходят.
Любые улучшения без него — гадание.

1. `metrika.yandex.ru` → «Добавить счётчик», включить Вебвизор.
2. Вставить код счётчика перед `</body>`.
3. Настроить цели — это главное:
   - клик по телефону (`tel:`)
   - клик по кнопке Telegram
   - отправка формы
   - прокрутка до блока с ценой

Без целей Метрика показывает только «сколько зашло», а нужно «сколько написало».

## 6. Обязательные блоки на странице

Проверьте, что на сайте есть всё из списка. Каждый пункт — причина,
по которой человек уходит к другому психологу.

- [ ] **Цена.** Прямо, цифрой. «Уточняйте» читается как «дорого».
- [ ] **Живое фото.** Не сток. Лицо, глаза, дружелюбно.
- [ ] **Образование.** Вуз, переподготовка, сертификаты — сканами.
- [ ] **Личная терапия и супервизия.** Часы. Для знающих клиентов это решающий аргумент.
- [ ] **С чем работаю.** Список запросов словами клиента: «не могу уйти
      из отношений», «постоянно тревожно», а не «коррекция аффективных состояний».
- [ ] **С чем не работаю.** Честность повышает доверие сильнее рекламы.
- [ ] **Как проходит консультация.** Снимает страх первого шага.
- [ ] **Отзывы.** 5-10 штук, можно анонимно, с разрешения клиентов.
- [ ] **Вопрос-ответ.** Закрывает возражения и даёт сниппет в поиске.
- [ ] **Кнопка записи.** Видна на каждом экране, ведёт в Telegram/WhatsApp.

## 7. Запросы, под которые писать тексты

Частотность проверяется в `wordstat.yandex.ru` по своему региону.

**Основные (высокая конкуренция, для главной):**
психолог онлайн · семейный психолог · консультация психолога ·
психолог [город] · психолог онлайн консультация

**Хвост (низкая конкуренция, быстрый результат — под отдельные статьи):**
как понять что нужен психолог · психолог по отношениям онлайн ·
что делать если постоянно тревожно · как пережить расставание ·
выгорание на работе что делать · сколько стоит консультация психолога ·
психолог или психотерапевт разница · как выбрать психолога

Под каждый хвостовой запрос — отдельная страница-статья 1000+ слов
с кнопкой записи внутри. Это самый дешёвый способ получить первых клиентов
из поиска: по таким запросам в топ выходят и молодые сайты.

## 8. Бесплатные площадки, дающие клиентов и ссылки

- **Яндекс.Бизнес** — карточка, показы на Картах и в выдаче. Обязательно.
- **Яндекс.Вебмастер** — добавить сайт, указать регион, загрузить sitemap.
  Без региона сайт не выходит по запросам «психолог + город».
- **b17.ru** — главный каталог психологов рунета, даёт ссылку и трафик.
- **Профи.ру, Ясно, Alter** — заявки сразу, но с комиссией.
